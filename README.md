# Student Budget Planner

A responsive budgeting tool designed for college and university students to plan monthly spending, set category budgets, and track their overall financial situation.

## Features

* Enter monthly income
* Choose from multiple currencies
* Set spending limits for different categories
* Track expenses across multiple categories
* Calculate total expenses
* Calculate remaining balance
* Calculate percentage of income spent
* Show overall budget status
* Highlight categories that exceed their budget limits
* Visual spending breakdown
* Reset planner
* Responsive design for desktop and mobile devices

## Supported Currencies

* USD
* BDT
* EUR
* GBP

## Budget Categories

* Housing
* Food
* Transportation
* Books & Supplies
* Phone & Internet
* Entertainment
* Shopping
* Other

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

This project was created as a practical student productivity and financial planning tool and as part of my web development learning portfolio.

## How to Use

1. Enter your monthly income.
2. Select your preferred currency.
3. Enter spending amounts for each category.
4. Set a budget limit for each category.
5. Review your total expenses and remaining balance.
6. Check the spending breakdown and budget status.
